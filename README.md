# 💊 Medicine Manager

A Django-based web application to manage and track medicines efficiently. This system is designed to help users organize medicine inventory, set reminders, and maintain dosage history.

---

## 🚀 Features

- Add, update, and delete medicine records
- Track dosage schedules
- Set expiry date reminders
- Responsive user interface
- Easy-to-use dashboard

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Django (Python)
- **Database**: SQLite (default, can be upgraded)
